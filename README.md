# Sistema de Gerenciamento de Vendas e Estoque

Sistema de linha de comando para controle de vendas e estoque, desenvolvido em C++
com foco em Programação Orientada a Objetos.

Projeto acadêmico desenvolvido durante a graduação em Ciência da Computação.

## Funcionalidades

- Cadastro e consulta de produtos em estoque
- Registro de vendas com baixa automática de estoque
- Alteração de produtos no estoque
- reajuste de precificação e nome de produtos
- exclusão de produtos
- atualização continua da lista de produtos com relação ao estoque
- 

## Conceitos aplicados

- Encapsulamento e separação de responsabilidades entre classes
- Herança e polimorfismo
- Gerenciamento manual de memória
- Compilação automatizada com Makefile

## Como compilar e executar

Requisitos: `g++` e `make`.

```bash
git clone https://github.com/SalvatoreDuke/Class_based_project.git
cd Class_based_project
make
./nome-do-executavel
```
